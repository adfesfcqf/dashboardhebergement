Crée ton espace

Chaque client a sa propre application Discord pour se connecter au dashboard (isolation totale, aucune donnée partagée). Il te faut ton code client, et une application Discord dédiée (gratuite, 1 minute à créer).

1
Va sur le Discord Developer Portal → New Application.
2
Onglet OAuth2 → copie le Client ID et génère/copie le Client Secret.
3
Toujours dans OAuth2 → Redirects, ajoute exactement l'URL affichée ci-dessous.

Identique pour tout le monde — c'est ton propre Client ID/Secret qui isole ton espace, pas cette URL.

Ce code te servira aussi à te reconnecter plus tard sur /login.
